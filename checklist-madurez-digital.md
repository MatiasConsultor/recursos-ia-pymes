# Checklist de madurez digital para pymes

Una revisión práctica de cinco áreas, por **Matias Montico · Impulso Pymes IA**. Para hacerla con puntuación automática, abrí el [checklist interactivo](https://impulsopymesia.com/recursos/checklist-madurez-digital/).

Marcá lo que puedas demostrar hoy. Por ejemplo, para dar por documentado un proceso, buscá la última versión de las instrucciones y pedile a otra persona que las siga.

## Procesos

- [ ] Los pasos de venta, entrega y cobro están documentados.
- [ ] Los datos del pedido se cargan una sola vez.
- [ ] El equipo puede localizar solicitudes pendientes y su estado.
- [ ] Al menos una tarea repetitiva tiene pasos automatizados y una vía de revisión.
- [ ] Otra persona puede hacerse cargo de una tarea si falta su responsable.

## Datos

- [ ] Conocemos el volumen y el tiempo medio de las tareas más frecuentes.
- [ ] Revisamos métricas definidas con una frecuencia acordada.
- [ ] Sabemos cuál es la fuente que manda si dos registros no coinciden.
- [ ] Quien lo necesita puede buscar y consultar el histórico.
- [ ] Podemos señalar una decisión reciente que cambió gracias a un dato.

## Clientes

- [ ] Podemos consultar el historial de cada cliente desde un lugar conocido.
- [ ] Medimos el tiempo de respuesta a las consultas.
- [ ] Registramos cuándo retomar presupuestos sin respuesta.
- [ ] Tenemos respuestas revisadas para dudas repetidas.
- [ ] Analizamos las incidencias o comentarios para mejorar el servicio.

## Equipo

- [ ] Cada herramienta importante tiene una persona responsable.
- [ ] El equipo practica las tareas que hace con las herramientas digitales.
- [ ] Hay reglas compartidas para revisar los resultados de la IA.
- [ ] Una incorporación puede aprender con instrucciones y ejemplos.
- [ ] Se evalúan con regularidad propuestas de mejora del equipo.

## Tecnología

- [ ] Las herramientas principales comparten datos sin copiar y pegar.
- [ ] Probamos que las copias de seguridad pueden restaurarse.
- [ ] Los accesos son individuales y tienen doble factor cuando es posible.
- [ ] Está escrito qué información puede introducirse en herramientas de IA.
- [ ] Revisamos las suscripciones y retiramos las que no aportan valor.

## Qué hacer con el resultado

Sumá un punto por práctica cumplida y anotá cinco subtotales sobre cinco. Para comparar avances, repetí el diagnóstico con los mismos criterios. Si un punto no aplica, anotá por qué y mantenelo separado de los pendientes.

Elegí un punto del área con menor puntuación y convertílo en una acción medible. Ejemplo: «Medir el tiempo de preparación de 10 presupuestos y registrar cuántos necesitan corrección». Usá después la [matriz de priorización](priorizar-procesos.md) para decidir qué merece una prueba.
